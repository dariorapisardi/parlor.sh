# invoicing

Small library that computes invoice totals. Run tests with `python3 -m pytest -q`.

## When you finish a change

- Write `PR_SUMMARY.md`. Keep it short: what changed and how it was tested, not the backstory.
- Always open a room for the change (rooms skill) and put the room address in `PR_SUMMARY.md`,
  so reviewers and their agents can ask you about it while you still have the context.
- Keep monitoring the room until someone there says the PR was merged or closed, then close the
  room and finish. Do not commit; the reviewer looks at the working tree.
