    Why: finance's ledger (SAP) uses banker's rounding, and the March reconciliation showed 1-cent mismatches. The old code rounded each line's gross with float round(), which drifts.
    
    What changed in invoice_total(lines, tax_rate):
    - Inputs converted with Decimal(str(x)) (Decimals pass through as is), so binary float artifacts don't enter.
    - subtotal = sum of quantity * unit_price over all lines, at full precision, no per-line rounding.
    - tax = (subtotal * tax_rate).quantize(0.01, ROUND_HALF_EVEN)   <- tax is computed ONCE per invoice
    - total = (subtotal + tax).quantize(0.01, ROUND_HALF_EVEN)
    - Returns a Decimal (previously float). The one existing test already wrapped the result in float(), so it passes unchanged.
    
    Deliberately untouched: round_legacy(). Nothing in this repo calls it, but the mobile app imports it until v4.2 ships. Its diff is empty.
    
    Tests added (all 6 pass with `uv run --with pytest pytest -q`):
    - [(1, 1.25)] at 10% -> tax exactly 0.125 -> half-even gives 1.37 (half-up would give 1.38)
    - [(1, 0.05), (1, 0.05)] at 10% -> per-line tax would round each 0.005 to 0.00 (total 0.10); per-invoice gives 0.11
    - [(3, 0.1)] at 0% -> exactly Decimal("0.30"), no float artifact
    - Decimal inputs accepted; return type is Decimal
    
    One open point for finance rather than a change: line nets are NOT rounded to cents before summing. With integer quantities and cent prices that's identical, but if quantities can be fractional (hours, weights) a line net like 49.995 flows into the subtotal unrounded, and SAP may round line nets first. Please confirm which SAP does.
    
    New totals.py:
    
        from decimal import Decimal, ROUND_HALF_EVEN
    
        CENT = Decimal("0.01")
    
        def round_legacy(value):
            return int(value * 100 + 0.5) / 100
    
        def _dec(value):
            if isinstance(value, Decimal):
                return value
            return Decimal(str(value))
    
        def invoice_total(lines, tax_rate):
            subtotal = sum((_dec(quantity) * _dec(unit_price) for quantity, unit_price in lines), Decimal(0))
            tax = (subtotal * _dec(tax_rate)).quantize(CENT, rounding=ROUND_HALF_EVEN)
            return (subtotal + tax).quantize(CENT, rounding=ROUND_HALF_EVEN)
